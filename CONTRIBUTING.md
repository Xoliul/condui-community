# Contributing to Condui Community

Bug reports, documentation improvements, and focused pull requests are welcome in
[Xoliul/condui-community](https://github.com/Xoliul/condui-community).

## Reporting a problem or proposing a change

Search existing issues first. For a bug, include the version or image revision, browser and operating
system, reproduction steps, and what you expected to happen. Share a minimal example with personal
and customer information removed. For a substantial feature, open an issue before implementing it
so its scope can be discussed.

## Submitting a pull request

1. Fork the public repository and make a focused change from its `master` branch.
2. Follow the setup instructions in [README.md](README.md). Use Node.js 24, run `npm ci` and
   `npm run build`, then check the affected workflow with `npm start`.
3. Explain the problem, the change, and how you tested it. Include screenshots for visual changes.
4. Read the contribution licence terms below and include the acknowledgement in your PR description
   or a comment from your own GitHub account. Each contributor must acknowledge their own work.

The public repository contains generated Community snapshots. Maintainers integrate accepted
contributions into Condui's canonical development repository before publishing a new snapshot.
Your contribution may therefore be incorporated through a snapshot rather than a direct merge of
your public PR. Maintainers should preserve contributor authorship and reference the original PR.
